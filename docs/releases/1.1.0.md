# PrintR 1.1.0

PrintR 1.1 adds more document formats, persistent settings, redesigned Windows and Android interfaces and a Linux agent. This is a direct-download development release, not a hosted service or a production support offering.

## Downloads and setup

- `PrintR.apk`: release-signed Android app, version 1.1.0, version code 3. Requires Android 8.0 or newer. Also available at [finnerty.me/printr.apk](https://finnerty.me/printr.apk).
- `PrintR-Agent-win-x64.zip`: self-contained Windows x64 agent and operator notes. Extract and run `PrintR.Agent.exe`. The standalone `PrintR-Agent-win-x64.exe` is the same executable.
- `PrintR-Agent-linux-x64.tar.gz`: self-contained Linux x64 background agent with a user-service installer. This is not a Linux desktop GUI. See [Linux setup](https://github.com/johnfinnerty-nz/PrintR/blob/v1.1.0/printr-linux-agent/README.md).
- `SHA256SUMS.txt`: checksums for the downloads. `PrintR-android-release.cer` is the public Android signing certificate, not a private key.

Windows PDF printing requires SumatraPDF. Office and OpenDocument conversion requires LibreOffice on the agent computer. Linux printing requires configured CUPS printers and the appropriate filters. Drivers determine supported paper, color and duplex options. Keep the agent on a trusted private network.

Important Android migration: this release uses a dedicated signing key, separate from debug builds. If an older debug-signed app is installed, uninstall it before installing this APK, then pair again. Uninstalling clears saved pairings and preferences. Later releases signed with this same release key can update it in place.

The Windows EXE is unsigned. Windows may display publisher or SmartScreen warnings. No trusted Windows code-signing certificate is included.

## Changes

- Added CSV, BMP, XLSX, PPTX, ODT, ODS, ODP and RTF handling alongside PDF, PNG, JPEG, TXT and DOCX. CSV prints as plain text, not a formatted spreadsheet.
- Added Windows Overview, Recent jobs, Settings and Diagnostics tabs. Fixed clipped header text and Settings action/Browse button borders at scaled display sizes.
- Added Android Print, Computers and Settings navigation, theme options and saved print defaults.
- Added persistent job history and deployment settings, upload and queue limits, processing timeouts and automatic uploaded-file cleanup.
- Added shared validation, isolated Office conversion profiles and Linux CUPS packaging.
- Added real Android emulator screenshots and user-provided Windows screenshots in the [gallery](https://github.com/johnfinnerty-nz/PrintR/blob/v1.1.0/docs/screenshots.md).
- Fixed Android CI setup to install `platform-tools` without requesting the obsolete SDK `tools` package.

## Validation and limitations

Validation includes 61 Windows unit tests, 31 Linux/shared unit tests and 15 Android unit tests per variant. Windows and Linux HTTPS mock smoke tests passed, as did real LibreOffice conversion of seven Office/OpenDocument formats on both platforms. Android lint passed with 0 errors and 11 warnings per variant. The signed APK passed installation, launch and same-key reinstallation on a fresh API 35 emulator.

John reports successful physical printing of DOCX, PDF, CSV and TXT on a Canon MX720 series Printer WS and confirms color, duplex, copies and page-range controls. This is user-reported testing on one printer, not an exhaustive format-by-option matrix. Native Windows TXT/CSV/image page ranges remain unimplemented; use PDF for page selection. A completed job means backend submission, not confirmation of paper output.

Clean-machine installation, upgrade and rollback need wider validation. Linux runtime checks used Ubuntu 22.04 under WSL; no ARM64 build is included. Direct Android printing remains PDF-only. LibreOffice conversion is not a full sandbox for hostile documents. See [full validation notes](https://github.com/johnfinnerty-nz/PrintR/blob/v1.1.0/docs/validation-1.1.0.md).
