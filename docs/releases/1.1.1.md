# PrintR 1.1.1

Android interface update. Windows and Linux agents are unchanged at version 1.1.0 and are included for convenience.

## Changes

- Replaced pill-shaped buttons with subtle 6 dp corners and reduced card/banner rounding to 8 dp. Other themed surfaces use similarly smaller corners.
- Fixed the Computers tab label splitting onto two lines. Navigation now measures the actual text size and shares available width intelligently. At very large accessibility text sizes, the row scrolls horizontally so labels remain complete and all tabs stay reachable.
- The Settings version label now comes from the build version.

## Install

Download `PrintR.apk` here or from [finnerty.me/printr.apk](https://finnerty.me/printr.apk). Android version name is 1.1.1 and version code is 4. The APK uses the same release certificate as 1.1.0, so install it over the signed 1.1.0 app without uninstalling or clearing data.

Older debug-signed builds still require uninstalling first and pairing again. Windows remains unsigned. The Windows EXE/ZIP and Linux x64 archive are byte-for-byte identical to the 1.1.0 packages. See [1.1.0 setup and limitations](https://github.com/johnfinnerty-nz/PrintR/blob/v1.1.0/docs/releases/1.1.0.md).

`SHA256SUMS.txt` contains all download checksums. `PrintR-android-release.cer` is the public signing certificate, not a private key. Certificate SHA-256: `f3504c2b93e15250878d2406db07f56f9e7ba6487056cbc93bc9a710dc1b886f`.

## Validation

- 15 Android unit tests passed for both debug and release variants.
- Debug and release lint passed with 0 errors and 14 warnings per variant. Warnings cover dependency updates, target API, existing certificate trust handling, backup metadata and an unused resource.
- Two emulator UI tests passed, covering all three tabs at 320, 360 and 411 dp widths with 1.0x, 1.3x and 2.0x font scaling. Checks verify single-line glyph bounds, selection, scroll reachability and subtle corner radii.
- The signed release APK successfully updated the signed 1.1.0 installation in place on an API 35 emulator. Android retained its original first-install timestamp. APK v2 signature verification passed with the existing release certificate.
- Real light/dark screenshots at 360 dp, including enlarged text and the selected Computers tab, are in the [screenshot gallery](https://github.com/johnfinnerty-nz/PrintR/blob/v1.1.1/docs/screenshots.md).

This patch does not alter printing or pairing storage. No new physical-printer test is claimed. Run the UI regressions on a disposable Android emulator using `gradlew connectedDebugAndroidTest`; its target is a debug build, not the user's release installation.
